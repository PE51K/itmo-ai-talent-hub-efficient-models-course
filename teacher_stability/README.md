The goal of this contribution is to evaluate the stability of ettin-encoder -400m teacher fine-tuning on SST-2 across different random training seeds. Previously, teacher results for 1%, 5%, 25%, and 100% of labeled training data were based on a single seed, making it impossible to estimate the run-to-run variation. So we added two more runs for each of these settings so that all five label fractions, including the existing 10% setting, could be compared over three seeds.

All eight additional runs were completed, and the results were summarized using mean accuracy, f1, and sample standard deviation. We added a script to run missing seeds, saved the per-run metrics, and updated the summary CSV and accuracy plot with error bars. Teacher validation accuracy ranged from 89.64 +- 1.80% at 1% labeled data to 95.83 +- 0.29% at 100%, indicating lower variation with more labeled data. Further runs for the k-center 10% subset are prepared but are not included in these results until completed.
